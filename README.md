## `01` — Engineering Profile

I build software with a focus on **maintainability, security, performance, and long-term scalability**.

My interests span full-stack development, backend engineering, database design, cloud technologies, and cybersecurity. I enjoy transforming complex requirements into well-structured systems that are practical to operate, test, and extend.

I believe professional software engineering is not about writing more code. It is about making deliberate technical decisions, understanding trade-offs, and building systems that remain reliable as they evolve.

- **Building:** Production-oriented web applications, mobile solutions, and business systems.
- **Engineering:** Clean architecture, API design, database integrity, and secure application development.
- **Exploring:** Go, Rust, advanced system design, and cloud engineering.
- **Improving:** Automated testing, CI/CD, observability, and engineering documentation.
